Findings

Potential Prompt Injection

Response matched controlled success indicators; verification is required

Impact: The target may be affected by prompt injection.

Missing Security Control

Trusted instructions and untrusted content are not strongly separated.

Immediate Containment

  1. Disable or require approval for sensitive tool actions reachable from affected prompts.
  2. Block the verified payload pattern while a durable control is deployed.

Recommended Corrective Measures

  1. Place system instructions, retrieved content, and user input in explicitly separated fields.
  2. Treat retrieved documents and tool output as untrusted data, never as executable instructions.
  3. Enforce authorization in application code for every tool call and sensitive operation.
  4. Add input-risk classification and output-policy checks around high-impact workflows.
  5. Use least-privilege tool credentials and require human approval for destructive actions.

How to Validate the Fix

  1. Replay the linked attack jobs and confirm the controlled marker is not obeyed.
  2. Test direct, indirect, encoded, and role-confusion variants.
  3. Confirm blocked prompts cannot trigger tools or change application state.

OWASP guidance: Separate trusted instructions from untrusted content and enforce downstream authorization.
